Copilot を agent mode で使うと、コードベースの調査、変更の提案、ファイルの編集、コマンドの実行などを自律的に行います。VS Code の Copilot Chat では、すべてのツール呼び出しやファイル編集をリアルタイムで確認できます。差分を確認して、個別の変更を承認または取り消し、エディターを離れずに追加のプロンプトを送って会話を調整できます。

この演習では、次の内容を学習します。

- アクセシビリティエージェントの作業をリアルタイムで監視します。
- 提案されたファイル編集をレビューして承認します。
- 進行中のセッションでエージェントに指示を追加し、ハイコントラストに加えてライトモードを追加します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ向けカスタムエージェントは、ハイコントラストモードを実装しています。作業中、デザインチームから追加の依頼がありました。既定のテーマが暗すぎると感じる利用者向けに、ライトモードへの切り替えも追加してほしいとのことです。新しい会話を最初から始める代わりに、既存のセッションに指示を追加して作業を広げます。

## Copilot の進捗を監視する

Copilot Chat ビューには、エージェントが実行する各ステップ、調査したファイル、実行したコマンド、提案した編集が表示されます。ファイル編集は差分と **Keep** / **Undo** の操作とともにチャットに表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、各ツール呼び出しを確認します。ファイルの読み取りや編集、実行を求めるターミナルコマンドなどが表示されます。
3. エージェントがファイルの編集を提案すると、差分がチャットに表示されます。
   - **Keep** を選択すると変更を承認します。
   - **Undo** を選択すると変更を取り消し、エージェントにもう一度試させます。
4. チャット上部の **Files changed** を開くと、セッション中にエージェントが変更したファイル全体を確認できます。

> [!NOTE]
> ターミナルコマンドの実行などで許可が必要な場合、エージェントは一時停止して **Allow** を表示します。内容を確認し、許可してもよいコマンドだけを承認してください。

5. エージェントがハイコントラストモードを実装し終えるまで待ちます。最後に、変更内容の概要が表示されます。

## エージェントにライトモードの追加を依頼する

ハイコントラストモードができたら、同じ会話でライトモードへの切り替えを追加します。同じチャットセッションを続けることで、エージェントは以前の作業のコンテキストを保持します。変更したコンポーネント、採用したスタイル、設定した local storage のパターンなどを把握しています。

1. Copilot Chat の入力欄に、次の追加プロンプトを送信します。

    ```plaintext
    Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
    ```

2. エージェントは既存の変更を調べ、ライトモードを追加する変更を提案します。
3. ハイコントラストモードと同じように、新しい編集を確認します。各差分で **Keep** または **Undo** を使います。
4. エージェントの方針が希望と異なる場合 (たとえば、切り替え UI を意図しない方法でリファクタリングする場合) は、チャット入力欄の **Stop** ボタンで停止して、明確な指示を追加します。

> [!TIP]
> 進行中のセッションに指示を追加すると、最初からやり直すよりも速く調整できます。「CSS を簡潔にして、セレクターの重複ではなく CSS 変数を使ってください」のように変更を依頼したり、「トグルを 3 つにせず、ライトモードを既存の設定パネルに追加してください」のように方針を修正したり、「両方のトグルにキーボードショートカットも追加してください」のように範囲を広げたりできます。

## 作業内容をレビューする

変更をコミットする前に、エージェントが変更した内容を確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが含まれます。
3. いくつかのファイルを開き、差分を確認します。カスタムエージェントから指定したアクセシビリティの手法 (ARIA 属性、キーボード操作、セマンティック HTML、local storage による設定の保持など) が反映されていることを確認します。
4. 問題がなければ、Source Control パネルから変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat の agent mode を使い、進行中のセッションを監視して指示を追加しました。ファイルの編集を確認しながら承認または取り消し、コンテキストを失わずに作業を広げる追加プロンプトを送信しました。

このレッスンでは、次の内容を学習しました。

- エージェントの作業をリアルタイムで監視する方法
- 個別のファイル編集を承認または取り消す方法
- 追加プロンプトで進行中のセッションに指示を送る方法
