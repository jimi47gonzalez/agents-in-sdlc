[**GitHub Copilot app**][about-copilot-app] は、エージェント主導の開発に使用するデスクトップアプリケーションです。GitHub Copilot CLI を基盤とし、GitHub とネイティブに統合されているため、リポジトリ、ブランチ、CI パイプラインをすぐに利用できます。すべての作業を自分で行うのではなく、複数のエージェントを分離されたそれぞれのワークスペースで並列に指示し、繰り返し作業を自動化するワークフロー向けに設計されています。Node.js のインストールとプロジェクトのコピーが完了したので、次はアプリをインストールしてリポジトリを接続します。

このレッスンでは、次の内容を学習します。

- GitHub Copilot app をインストールしてサインインします。
- GitHub リポジトリからプロジェクトをアプリに追加します。
- テンプレートによって用意されたバックログを含め、ワークスペースを確認します。
- クイックチャットを試して、アプリについて質問します。

## シナリオ

チームは、増え続けるバックログに対応するために AI エージェントを導入しています。Copilot app では、issue の選択、エージェントの実行、変更のレビュー、プルリクエストのマージを 1 か所から指示できます。このレッスンでは、アプリをインストールして接続し、プロジェクトについての会話を始められるようにします。

> [!NOTE]
> 対象となる Copilot プランが必要です。Copilot Free、Copilot Student、または有料プラン (Pro、Pro+、Business、Enterprise) を利用してください。Copilot Business または Copilot Enterprise を使用している場合、管理者が **GitHub Copilot app** ポリシーを有効にしておく必要があります。

## GitHub Copilot app をインストールして設定する

GitHub Copilot app を使うには、まずアプリをインストールします。Windows、macOS、Linux 向けのバージョンが用意されています。アプリをインストールして認証し、Tailspin Toys リポジトリを追加します。

1. ブラウザーで [GitHub Copilot app のランディングページ][download-app]を開きます。
2. 使用しているプラットフォーム向けのアプリをダウンロードし、ランディングページの手順に従ってインストールします。
3. インストールが完了したら、アプリを開きます。
4. **Sign in to GitHub** を選択し、画面の指示に従って認証します。データ所在地が設定された GitHub Enterprise Cloud を使う場合は、**Use GitHub Enterprise** を選択し、求められたら `*.ghe.com` のホスト名を入力します。GitHub Enterprise Server はサポートされていません。
5. オンボーディングでリポジトリを選択する画面が表示されたら、テンプレートから作成した Tailspin Toys リポジトリを選択します。リポジトリの選択をスキップし、オンボーディング後にプロジェクトを追加することもできます。
6. テーマの選択を求められたらテーマを選び、オンボーディングを完了します。
7. サイドバーの **Sessions** にリポジトリが表示されているか確認します。すでに表示されている場合は、追加する必要はありません。
8. リポジトリがまだ接続されていない場合は、**Sessions** の横にある **+** を選択して新しいセッションを作成し、**Add GitHub repository** を選択します。前提条件のレッスンで記録した所有者とリポジトリ名を入力します。
9. リポジトリがサイドバーに表示されていることを確認します。このレイアウトでは、`tailspin-toys` などのリポジトリフォルダーが **Sessions** の下にまとめられ、その下に個々のセッションが表示されます。

## ワークスペースを確認する

プロジェクトを接続したら、ワークスペースの構成を確認します。アプリのサイドバーはいくつかの領域で構成されています。

- **New**: Copilot との新しいチャットセッションを開始します。
- **Pull requests**: アプリの GitHub ネイティブ統合を通じてプルリクエストを表示します。アプリを離れずに、プルリクエストの参照や絞り込み、CI 状態の確認、レビューができます。
- **Issues**: Issue を参照して絞り込んだり、Issue からセッションを開始したりできます。
- **Automations**: スケジュールまたはオンデマンドで実行する、保存済みのエージェントタスクです。To-do リストの管理、定期的なプロジェクト保守、その他の面倒な作業を任せるのに役立ちます。まとめでは次のステップとして紹介しますが、ワークショップ中の追加演習ではありません。
- **Customize**: MCP サーバー、プラグイン、skills などのコンポーネントで Copilot app に機能を追加します。Playwright MCP を設定する際に使います。
- **Chats**: 独自のブランチやワークスペースを必要としない、質問やブレインストーミング向けの簡易的な会話です。最初のチャットを始めると表示されます。表示されない場合は **Sessions** の横にある **+** を選択して、最初のチャットを始めます。
- **Sessions**: リポジトリフォルダーと、そのエージェントセッションをまとめます。リポジトリ名 (たとえば `tailspin-toys`) を選択してリポジトリビューを開くか、その下にあるセッションを選択して会話に戻ります。セッションはそれぞれ専用の分離されたワークスペースで実行されるため、変更を競合させずに複数のセッションを同時に使えます。星評価を追加するレッスンで最初のセッションを始めます。

ワークショップを進めながら、ワークスペースの各機能を確認します。

> [!TIP]
> 操作方法がわからない場合や、何かが可能かどうか知りたい場合は、Copilot に質問してください。手順を案内してくれます。

### 用意されたバックログを確認する

バックログのないプロジェクトはほとんどなく、Tailspin Toys も例外ではありません。テンプレートからリポジトリを作成したときに用意されたバックログを確認しましょう。

1. サイドバーの **Sessions** で、個別のセッションではなく Tailspin Toys のリポジトリフォルダーを選択します。次に、リポジトリの上部ナビゲーションで **Issues** を選択します。
2. Issue 番号を決めつけず、次のタイトルを探します。

   - Allow users to filter games by category and publisher
   - Update our repository coding standards

3. Issue を選択して詳細を読みます。Issue からエージェントセッションを開始することもできます。最初の小さな変更を完了した後、フィルター機能の Issue から作業を始めます。

> [!NOTE]
> **Issues** と **Pull requests** の一覧は自動的に絞り込まれ、Copilot app に追加したリポジトリの項目だけが表示されます。ほかのリポジトリの作業項目を表示するには、そのリポジトリをアプリに追加します。

## クイックチャットを試す

アプリ自体について質問すると、アプリの使い方に慣れることができます。その用途には **quick chat** が適しています。クイックチャットでは、ブランチや worktree を作成せずに質問やブレインストーミングができます。セッションを作る必要がない、短時間で済む一時的な質問に最適です。

1. サイドバーの **Chats** の横にある **+** を選択して、新しいチャットを開きます。**Chats** がまだ表示されない場合は、**Sessions** の横にある **+** を選択して最初のチャットを始めます。開始後に **Chats** が表示されます。
2. アプリのセッションの仕組みについて、次の質問を送ります。

   ```plaintext
   How does the GitHub Copilot app use worktrees?
   ```

3. 会話ビューで回答を読みます。各セッションが分離された独自の git worktree で実行されるため、変更を競合させずに複数のエージェントを並列実行できることがわかります。会話はいつでも続けられ、新しいチャットも開始できます。

- ワークスペースを確認し、**Issues** で用意されたバックログを見つけました。
