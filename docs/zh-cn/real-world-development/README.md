通过真实场景、完整应用和共享待办列表，探索 GitHub Copilot 如何融入软件开发生命周期。你将迭代规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为棋盘游戏提供众筹平台，并采用开发者主题。团队的待办事项已作为 GitHub 议题创建，可供你处理，其中既有筛选和分页等功能任务，也有无障碍体验和编码规范等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。请选择适合你的开发环境。每个研讨会都有自己的设置流程，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义智能体、Playwright MCP、Agent Merge，以及实用的斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、协作使用画布，以及管理 GitHub 议题和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub 议题分配给异步运行的智能体、引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
